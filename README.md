# DriveSchool

Премиальный сайт автошколы с регистрацией, личным профилем, онлайн-записью на автомобиль, журналом и админ-панелью.

## Запуск

1. Создайте PostgreSQL-базу `avto` (на этом компьютере доступен порт `5433`; при необходимости измените его в `.env`).
2. Выполните [schema.sql](schema.sql) в этой базе.
3. Скопируйте `.env.example` в `.env` и задайте секрет JWT и данные администратора.
4. Из папки проекта запустите `npm start`, затем откройте `http://localhost:3002`.

Укажите пароль PostgreSQL в локальном `.env`; не публикуйте этот файл. Перед запуском задайте надёжные значения `PGPASSWORD`, `JWT_SECRET` и `ADMIN_PASSWORD`.
